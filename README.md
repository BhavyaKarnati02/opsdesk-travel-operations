# OpsDesk – Intelligent Travel Operations Management System

## 1. Project Overview

OpsDesk is a travel operations management system designed to help travel support teams manage customer issues in an organized and efficient way.

It brings related travel complaints and service requests together under a unified case, helping support teams maintain customer context and track issue progress.

## 2. Problem Statement

In traditional travel support workflows, related customer complaints are often handled as separate tickets. This can lead to:

- Repeated collection of customer and booking information.
- Fragmented communication and issue history.
- Difficulty identifying urgent travel problems.
- Delays in assigning and tracking support requests.

## 3. Proposed Solution

OpsDesk organizes related support tickets under a unified case. It provides a centralized interface to manage cases, track priorities, view related tickets, and monitor support operations.

## 4. Key Features

- **Case Management:** Create and manage customer support cases.
- **Ticket Linking:** Group related tickets under one case while retaining individual ticket details.
- **Priority Management:** Classify cases by urgency.
- **SLA Tracking:** Display service-level priorities and target response times.
- **Smart Routing:** Support assignment based on case information and routing rules implemented in the application.
- **Communication Management:** View and manage communication-related information.
- **Dashboard:** Monitor operational activity and case statistics.
- **Reports:** View charts and export available report data as CSV.

## 5. Technology Stack

- Frontend: React
- Build Tool: Vite
- Authentication: Firebase Authentication
- Database: Cloud Firestore
- Hosting: Vercel
- Version Control: Git and GitHub

## 6. Application Workflow

1. The support user signs in to OpsDesk.
2. The user views the operational dashboard.
3. A customer issue is registered as a case.
4. Related tickets are linked to the case.
5. The case is categorized and assigned a priority.
6. Support teams track the case and its related information.
7. Dashboard reports help monitor operations.
